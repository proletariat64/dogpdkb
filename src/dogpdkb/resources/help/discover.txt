# Discovery inputs and outputs

--book selects the subscription. Without --source, all enabled sources are
scanned. Repeat --source KEY to restrict the scan. A Yuque source calls the
configured Skylark listing; --listing PATH substitutes a complete offline
skylark-listing-1 artifact when exactly one Yuque source is selected. The book
URL, complete flag, advertised count, unique IDs and TOC are validated before
subscription filtering. Existing unregistered Yuque corpus requires init-state.

```json
{"schema":"skylark-listing-1","complete":true,"book":{"book_id":"1","url":"https://example.invalid/team/book","items_count":1},"documents":[{"document_id":"42","title":"Example","version":"2026-11-13T00:00:00Z"}],"toc":[]}
```

A directory source recursively scans regular Markdown, ignoring symlinks,
hidden entries, and _inventory. Selected Markdown bytes are frozen in wash;
originals are not changed. Versions are content digests, not timestamps.

The persisted dogpdkb-differences-2 contains schema, book (key/name/sources),
run_id, captured_at, selected source keys, per-source listings and cutoffs,
selected documents, absent and ignored identities. A row has a scoped
document_id, source_key, source_document_id (Yuque ID or relative filename),
version, title, path, source_url, format, metadata, reasons, and local facts.
Directory rows include frozen_input. Pending work is acknowledged only by
actual stage results, not inferred from discovery.

stdout gives run and differences paths and selected/absent counts. When any
selected scan fails, no combined differences or new observations are committed.
Unselected sources are not observed or marked absent. Absence never deletes
published content. Discover changes no corpus or graph and does not run OCR.
