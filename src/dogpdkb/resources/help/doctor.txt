# Offline preflight

--package skips instance loading and checks only the installed distribution.
Otherwise config/book resolution is required. Repeat --source KEY to restrict
checks to registered sources, or use --dir PATH for a directory-only scope.
Doctor checks selected directory paths, sync output paths and necessary tools'
public --help entry points, not their doctor commands. Skylark is checked only
for a selected Yuque source. No business request, token validation, SSO login,
source download, OCR, extraction or corpus publication is performed. A passing probe
proves entry-point availability only, not complete tool compatibility or remote
service availability. Tool help itself must obey its own read-only contract.

--json returns a JSON array of checks. Each row has name and status (ok/fail).
Configuration checks add book and sources on success; configuration and path
failures give a reason. Tool probes add exit_code. The package-only result is
[{"name":"package","status":"ok"}].
Human output prints checks instead. Exit 1 means at least one failure; inspect
the named check and fix configuration/installation before sync. Interrupted
tool probes propagate 130/143. Repeating rechecks and may launch the same tool
help subprocesses; unlike reading dogpdkb help, doctor is an explicit probe.
