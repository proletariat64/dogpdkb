# Read-only observation contract

--run accepts an ID, a run directory, or run.json; the run's book key must match.
Without it, choose the newest active run, otherwise the newest recorded run by
start time and record mtime. --watch polls every 1 second; --json alone outputs
one JSON object, --watch --json outputs one independent object per line (JSONL).
Stop a watch with Ctrl-C (exit 130). No configuration/corpus/graph/state is written,
no write lock is acquired, and no tool or remote authentication is needed.

No recorded runs yields {"schema":"dogpdkb-status-1","status":"no-runs","runs":0}.
Otherwise output contains the run fields documented in the common contract,
schema dogpdkb-status-1, recorded_status (saved status), status (observed status),
alive (boolean), elapsed_seconds (nonnegative number or null if dates are
unparseable), and run_directory (absolute path). A recorded running run becomes
observationally interrupted when its owner is not live and holding its lock.
progress shows current/last completed phase, completed/in_flight/pending/failed
and last progress time. Counts may be null: neither limits nor a missing report
prove how much work is in flight. publication separates corpus from graph;
next_action describes what to do next. facts reflects current state for the
run's selected sources. Observed, raw, corpus and graph facts are independent;
corpus_vs_graph compares saved SHA-256 witnesses, even at the same version.

handoff (dogpdkb-handoff-1) records versioned failure/evidence rows and scope.
unknown is not unsent. none authorizes nothing; document_next_batch is for
proved-unsent OCR; graph_batch is for exact saved graph scope. eligibility is
advisory; writers revalidate. Abrupt owner loss can show provisional evidence.
The watch never retries. Purge can delete the handoff, not version suppression.
