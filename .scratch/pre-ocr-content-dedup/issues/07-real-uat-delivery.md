# 07: 真实文件 UAT 与最终交付验收

Type: task
Blocked by: 02, 04, 05, 06
Status: ready-for-agent

**What to build:** 用 co.bot 已固定的 98 对真实材料运行 mdcompare，并完成全部契约的集成验收、使用文档、代码审查和交付记录。UAT 必须使用真实文件，不用合成文件冒充现场证据。

- [ ] 先阅读已核验资料包指南，按最终 schema 创建独立适配清单，明确旧文件为历史 OCR 富化文本、新文件为 raw；不把路径索引直接当正式输入。
- [ ] 使用固定 98 对而非持续变化的生产目录，按稳定 ID 配对；可远端只读运行或同步受限副本至当前工作区，资料和正文报告保持私有且不提交 Git。
- [ ] 对 98 个 incoming 分别生成恰好一个结果，核对统计守恒、原因码、差异证据上限和重复运行确定性；不以 27／45／26 人工分类作为 CLI 动作金标准，不设过滤率目标。
- [ ] 确认缺旧 raw 或资源证据时保持 UNKNOWN，不能确认图片未变或 OCR 可复用；重点核查指南所列金额、字段、规则及不明转写案例。
- [ ] 记录真实资料实际覆盖与缺口。真实材料不足以证明正常旧 raw 对新 raw 或完整图片复用时如实报告，不伪造已成功发布基线；合成反例属于开发测试，不冒充真实 UAT。
- [ ] 不得远端抓取、运行 OCR、Graphify、生产同步、推进基线或修改现场输入与同步状态；仅生成调用者指定的报告。
- [ ] 使用文档说明安装调用、清单／报告 schema、规范化、比较预算、原因码、动作优先级、退出码、隐私边界及历史输入限制，明确比较结果不等于业务正确或生产上线证明。
- [ ] 核对规范全部必测项和六种动作，运行适用类型检查及仓库要求的检查，最终运行完整测试套件，完成代码审查并修复发现的问题。
- [ ] 交付记录列出真实 UAT 命令、输入来源、结果计数、退出码、限制与审查证据；按本地 tracker 规范附验证依据并解决所有 tickets，不把资料整理当作 UAT 执行成功。
