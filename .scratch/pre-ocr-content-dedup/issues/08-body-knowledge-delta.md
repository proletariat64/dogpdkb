# 08: 正文知识复用与增量

Type: task
Blocked by: none
Status: resolved

## Scope

用户要求从整篇严格一致转向知识去重，并明确图片、OCR完全忽略。
新增只读 `mdcompare knowledge`，保留旧 `compare` 兼容契约。
最新规范：[正文知识规格](../knowledge-spec.md)。

## Acceptance

- 逐块报告 reuse/add/revise/old_only_review/unresolved，保留实际来源与行号。
- 支持部分复用、格式及明确数量单位等价；相似度仅定位修订候选。
- 图片及明确标记的OCR区块不参与判断，不读产物，不产生待办或阻塞。
- 保护主体、条件、正文链接目标、代码、表格绑定与步骤顺序。
- 历史输入不以缺旧raw整体挂起；不猜测未标记历史片段来源。
- 私有报告、证据上限、输入保护、漂移检查及旧命令兼容通过。
- 完整真实UAT与开发探针分开，报告知识块计数及限制，不将候选冒充自动合并。
- 仓库检查与独立反例检查通过；不修改生产输入、基线或同步状态。

## Answer

- 已交付 `mdcompare knowledge`、正文块提取与对齐、来源引用、私有报告及旧命令兼容。
- 图片/OCR完全排除；历史旧raw缺失不再整体UNKNOWN。支持局部复用、明确数量等价、修订候选与旧内容待判；没有宣称通用语义判等。
- 完整真实UAT：4,752篇主批次、16篇旧候选追加、固定98对；两轮结果相同，追加结构类型字段外无判定差异。
- 主批次1,895篇正文全复用、1,436篇部分复用；排除标题的可复用正文块116,420个。0 UNKNOWN、0输入错误；上下文不明与修订保留REVIEW。
- `make check`通过，790项测试；最终68项知识测试再验通过。离线wheel/sdist构建和安装态新命令验证通过。
- 独立复核13个图片排除、主体、条件、链接目标反例通过。9,500个全量源文件及307个固定资料文件逐字节未变。
- [真实验收与限制](../../../docs/mdcompare-knowledge-uat.md)：标题来自文件名适配，1,338篇存在主体上下文待判；真实跨文档复用0；无通用语义模型、生产写入或发布。
