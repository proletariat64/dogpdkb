# 01: 独立 CLI 与无资源文档比较

Type: task
Blocked by: None (can start immediately)
Status: ready-for-agent

**What to build:** 提供可独立安装、离线运行的 mdcompare compare，调用者传入 baseline、incoming 清单及报告位置即可完成无资源文档比较。确定后续切片共享的版本化输入与结果契约；尚未具备验证能力的资源或历史输入必须保守返回 UNKNOWN。

- [ ] 命令可独立安装和调用，不依赖运行中的 dogpdkb、登录态、网络或 LLM；不执行 OCR、同步、发布或基线推进。
- [ ] 清单校验 schema 版本、必填字段及类型，声明 raw／历史富化输入，包含元数据、资源及可选 OCR 来源记录；保留后续功能所需的明确状态，不用布尔值混淆未知与未变。
- [ ] 身份为来源知识库加文档 ID；同知识库重复 ID 或无法配对的非法身份全局失败，跨知识库相同数字 ID 不冲突。文件名、路径不作为身份。
- [ ] 按长度及直接字节比较 raw；无资源同文输出 SKIP_VERIFIED，改名／移动输出 UPDATE_METADATA_ONLY，正文变化输出 UPDATE_TEXT_REUSE_OCR 且 OCR 状态为不适用。
- [ ] 新增文档明确标新增并建议处理或说明未知原因；baseline 独有文档单列为未出现在 incoming，不推断远端删除。纯同步时间戳变化独立呈现，不触发内容变化结论。
- [ ] 结果 schema 包含身份、文本／资源／元数据／OCR 状态、六种动作、原因码、规则版本、分类统计和错误摘要；每个 incoming 恰好一个结果，空输入有效，输出顺序稳定。
- [ ] 退出码 0 表示完成且无未知，2 表示完整报告含未知或逐项错误，1 表示全局失败；普通差异不视为执行错误。
- [ ] 只写显式指定的报告位置，报告采用私有权限和原子发布；输入及已有成功基线不变，正常日志不含正文、凭证或完整资源 URL。
- [ ] 以 CLI 黑盒测试上述行为、畸形清单、重复 ID、跨知识库 ID、空输入、输入未变及基础报告发布失败；不使用内部调用次数作为断言。
