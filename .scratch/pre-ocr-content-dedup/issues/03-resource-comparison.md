# 03: 资源独立比较与变化资源清单

Type: task
Blocked by: 01
Status: ready-for-agent

**What to build:** 调用者可独立确认资源相等、变化或未知，并取得需要处理的资源清单；Markdown 相同或 URL 相同均不足以证明资源未变。

- [ ] 比较调用者提供的本地资源字节或具有明确可信契约的不可变版本证据，不执行下载；仅 URL、缺失字节或不可验证证据返回资源未知。
- [ ] 同 URL 不同字节必须识别为变化，不同 URL 相同字节可识别为资源相等，但不抹掉链接本身的文本／元数据变化。
- [ ] 结构分析能够关联清单资源与 Markdown 使用位置；图片及其他外部资源均纳入验证。无法完整识别或关联的依赖保持未知，不因清单遗漏而误跳过。
- [ ] 资源顺序、重复次数、标题、替代文本及链接含义保留；不因字节相同而折叠出现位置或覆盖正文差异。
- [ ] 明确新增／变化的资源输出 PROCESS_CHANGED_RESOURCES 与所需资源列表；混合未知时保留已确认局部变化，未知不得被掩盖为整篇可安全处理或跳过。
- [ ] 资源相等与 OCR 可复用分别输出；本票不具备完整 OCR 证明时保持 OCR 未知或需处理，不能仅凭原图相等跳过。
- [ ] CLI 黑盒覆盖同 URL 换图、不同 URL 同字节、长截图仅一位数字变化、缺资源、资源顺序／次数／替代文本变化，以及其他外部资源。
