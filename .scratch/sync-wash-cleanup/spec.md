# Sync wash 清理规格

Status: ready-for-agent

## 目标

让日常 sync 在流程结束后回收本次 wash 的成功临时产物，保留失败排查材料；
提供手动 purge 彻底清除所选 wash。决策索引见 [规划地图](map.md)。

## 自动清理

- 仅在 sync 真正 completed 或 partial 后，持有本批写锁时清理本次 run。
- 无工作完成也适用；计划暂停虽返回 0，不触发清理。
  failed、interrupted 和仍在运行的批次不自动清理；不扫描历史 run。
- 删除成功部分的下载、处理、发布见证等临时副本及重复 Graphify 工作区。
- 保留失败文档已有的 Markdown、相关本地图片、报告，以及身份、版本、
  步骤、命令和退出码/原因。OCR 失败后正文或编译成功，仍保留 OCR 失败材料。
- 未成功获取的输入如实记为缺失，不补跑工具。Graphify 整批失败时，
  正式语料已有且字节一致的输入可直接引用，避免另留整套候选图；
  仅存在于 wash 的必要失败输入仍须保留。
- 保留简要运行结果供 status 和后续 agent 查询；记录已清理的产物，
  不把已删除路径继续当成可读、可恢复输入。
- partial 不承诺恢复原 run；后续 agent 判断失败后通过新 run 处理。
  不新增自动重试或解除同版本失败抑制机制。
- 清理失败写 stderr，保持 sync 原有退出码和业务结果。

## 持久性边界

- 后续同步所需的最新原始比较基线、相关资源和有效复用输入独立于 wash 保存。
  不保留每个成功 run 的全套副本，不扫描搬迁历史 run，不建立通用引用管理平台。
- 清理不改变原始输入与已 OCR 语料的比较语义，不因输入删除导致不必要的重新处理。
- 具体文件布局由实现选择；不修改外部工具代码，不侵入其算法或缓存格式。

## 手动 purge

```bash
dogpdkb purge --book BOOK --run RUN
dogpdkb purge --book BOOK --all
dogpdkb purge --book BOOK --run RUN --force
```

- 继承现有配置选择规则。run/all 必须二选一；仅作用于所选 book 的 wash。
- 删除目标 run 的全部 wash，包括自动清理留下的失败材料和运行记录。
- 默认允许 completed/partial；丢弃暂停、失败或中断 run 必须 force。
  批量选择含这些 run 而缺少 force 时，报错且不执行本次删除。
- 遵守同一 book 写锁，不终止活跃 sync，不越过路径边界。
- 不删除正式语料、正式图谱、持久状态、必要持久输入或工具缓存。
- 手动删除错误返回非零；不调用外部工具，不执行重试或回填。

## 验收

1. 成功批次回收大体积临时文件，status 仍可查询简要结果。
2. 混合 partial 批次删除成功副本，失败 Markdown、相关图片及报告仍可读取。
3. OCR 失败但图谱成功，失败材料仍保留；失败图谱不丢失仅存于 wash 的必要输入。
4. 清理后的无变化同步与真实增量保持正确比较、复用、版本推进和失败抑制行为。
5. 暂停、中断、整批失败不自动清理；清理错误不改变 sync 退出码。
6. purge 的 run/all、force、写锁和越界拒绝通过公开 CLI 验证。
7. purge 可移除失败材料，但正式语料、图谱、持久状态和工具缓存不变。

## 不做

历史状态兼容、自动重试、外部 agent 调度、容量/保留期平台、Web 发布、
修改 Graphify/Yuque 或生产数据清理。本规划不等于已实现或通过真实 UAT。
