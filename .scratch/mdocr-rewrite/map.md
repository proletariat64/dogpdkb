## Joint new contract

`mdocr plan --mode paddle|llm [--input FILE|--list JSON|--directory DIR] [--output FILE|--output-dir DIR] --plan FILE`.
Options: `--model`, `--effort`, `--prompt-file`, `--token-budget`, `--request-budget`, `--concurrency 1|2|3` (default 3), `--max-seconds` (wall time before admission; default 900), `--endpoint` (Paddle only), `--download` (network image resolution only when explicit), `--selection JSON` (optional map of source absolute path to image targets; `[]` selects none), `--cache-dir` (optional persisted success cache). No `--list` shape other than array of strings. `mdocr run --plan FILE --result FILE [--retry-failed]`: exit 0 completed, 2 structured incomplete, 1 preflight/internal error, distinct usage and interrupt semantics. `--retry-failed` explicitly retries known failed requests, never unknown. Model flags only LLM. No historical `batch`, `ocr` or `prepare` requirement; replace obsolete help and test expectations for retired public contracts with equivalent new coverage, never remove relevant business checks.

Planner module `mdocr.plan` exposes `plan_command(args)->int`, `read_plan(path)->dict`. Plan schema `mdocr-plan-2`; `settings` keys `mode, model, effort, prompt` (exact text), `token_budget, request_budget` (null unlimited), `concurrency, endpoint, max_seconds, cache_dir`; `documents` rows `document_id` (stable stable opaque string, use absolute source string for orchestrator mapping), `path`, `sha256`, `output`, `images` (occurrence-order list); image fields `id` (stable unique within doc), `resource_id` (source target for evidence), `original_link` (link resolved for output including URL), `start/end` Unicode positions, `source_path` (snapshot/local immutable witness path), `sha256`, `selected`, `error` (null or machine reason). Omit unavailable byte witness only with explicit error/unselected. Plan-only may freeze remote image bytes on explicit `--download`, never calls OCR. Output file is protected, as are plan/result, original inputs, images, prompt and output paths. Relative unselected images require care: preserve non-replaced authored bytes, report unresolved/skipped explicitly. Planning shape and invocation visible machine-parseable, no assets in output projection.

Runner module `mdocr.runner` callable `run_command(args)->int`. Result `mdocr-result-2` with `plan_sha256`, `status`, `causes`, `documents`, `concurrency`, `budget`, and persisted request ledger. Each document: `document_id`, `path`, `status`, `output` (null unless completed), `resources` (ordered occurrence rows with ids, status, reason), `ocr` evidence object at completion. OCR evidence `mdocr-ocr-2`; `configuration` binds mode/model/effort/prompt/schema/Paddle preprocessing; `images` unique by `resource_id` for consumer mapping, with `source_path`, `source_sha256`, `artifact` (complete canonical OCR block), `artifact_sha256`, `status: success`. LLM evidence additionally binds complete input through `context_sha256`. Report or artifact paths absolute. OCR block envelope: start marker `<!-- mdocr:ocr-begin v=2 id=... -->`, metadata in code-owned sentinel/fields (include mode, source SHA-256; no raw URLs within comments), Markdown reference to the original image, converted body, `<!-- mdocr:ocr-end -->`. Escape/validate untrusted values; recognize image occurrence only outside fenced/inline code and existing OCR blocks; require safe inline links and preserve all text outside spans. Report is exclusively owned by the bound plan; separate output collision protection including report vs any input/plan/output. Ledger admission durable before sending. Keep completed outputs and request proofs; persist successful patches before publication. A selected error/hold does not publish a misleading completed document. Unselected refs are not inferred success. Distinct mode/context in caches. A plan-wide lock protects admissions from concurrent resumes.

Bridge `mdocr.llm` exposes `LlmClient(model, effort)`, `preflight()`, `convert(markdown, images, prompt)` (images list `{id, path}`; Markdown already contains stable anchors, no remote image target in sent text), `token_upper_bound()` (validated ceiling including max output, conservative full provider/model bound is acceptable; return None if not trustworthy). Convert returns dict `patches` list `{id, kind, markdown, uncertainty}`, `usage_tokens` integer/null. Bridge raises typed `LlmError` with `.status` int/null and `.reason`; timeout after potential submission is unknown. Strict provider schema `mdocr-image-patches-1`; code validates exact IDs and no control delimiters; runner owns publication, budgeting and replay; bridge must never retry inference. `DEFAULT_PROMPT` exported by planner or a separate data module shared by CLI/runner; keep prompt packaged. Real Mermaid parsing in standard LLM mode, not a regex standing in as parser. Package bridge assets; make Node/Pi optional for base CLI.
