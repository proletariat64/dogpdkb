# dogpdkb CLI 编排器重写

Status: implemented
Date: 2026-11-12
Scope: implemented, independently reviewed, verified and delivered on rewrite/cli-orchestrator

## Problem Statement

维护者需要每天通过 crontab 同步知识库并编译更新，能够按步骤运行、查看进度，并在部分内容失败时继续提供可用知识。当前编排器已有 14,981 行，直接调用独立工具内部实现，又保留多代流水线、历史兼容和复杂的清理处置逻辑，使一个串行程序难以维护、诊断和安全修改。

失败后的人工或 agent 处理需要真实结果和必要输入，不需要程序再内置一套异常处置平台。维护者也不希望重写引发历史回填、全量图谱提取、现有数据丢失或 Web 发布行为改变。

## Solution

重写为只负责范围选择、计划、串行 CLI 调用、结果记录和只读观察的编排器。保留 discover、apply、update-graph、sync 的操作方式，底层只留一条实现；mdocr、mdcompare、Graphify 和 Skylark 保持独立工具边界。缺少所需公开能力时先补工具 CLI 或 MCP 产物合同，不在编排器复刻工具内部逻辑。

默认流程完成整批扫描、下载、比较、计划、OCR 和图谱更新；可停在计划处检查并显式恢复。OCR 或单篇编译失败不阻断可用集合；失败和不明结果持久移交定时清理 agent，同版本失败不参加日常自动重试。Web 独立，既有语料与图谱保留为起点。目标编排器规模为 4–6k 行，职责预算约 4,850 行。

## Implementation Decisions

### 工具边界与职责

- 编排器只拥有范围选择、动作策略、顺序、调用结果和真实成功记录。mdocr、mdcompare、Graphify 仅通过独立公开 CLI 调用；Skylark 通过公开 CLI 或 MCP 调用。
- 禁止静态或动态导入这些工具包，禁止通过自有子进程脚本绕回工具内部，禁止复制工具提取、比较、OCR、缓存或图合并算法。
- 工具 CLI、MCP endpoint 和文档化 JSON、Markdown、manifest 是唯一集成合同。只检查公开 schema、退出码及产物可用性，不把内部节点身份、OCR block 格式、模型常量或缓存布局写成 fatal 条件。
- 工具缺能力时先核实并修改其公开接口，不降级到内部调用。prepared image 和 OCR block 的制作、格式检查及缓存归 mdocr；比较规则归 mdcompare；提取、来源替换、节点重映射及图合并归 Graphify。
- 保留产品策略、稳定来源身份和真实版本事实；删除旧执行器、历史状态导入、旧参数转发、重复审批和动态 handler 注册框架。命令名可以保留，不承担旧实现和旧状态兼容。

### 命令、整批顺序与计划

| 命令 | 合同 |
| --- | --- |
| discover | 扫描完整远端清单、判断变化，输出差异清单；不下载正文 |
| apply | 消费清单，整批下载、比较、生成计划、OCR，更新正式语料并输出 manifest |
| update-graph | 消费 manifest，通过 Graphify CLI 编译并提交图谱 |
| sync | 串行调用同一组职责，与分步执行共用实现 |
| status | 只读查看当前、最近或指定 run，支持 JSON 和 watch |

- 不增加同义 plan/execute 顶层命令。整体顺序为扫描、全批下载、全批比较、计划、全批 OCR、语料落盘与 manifest、图谱更新；下一阶段等待当前阶段结束。编排器不建并发工作池，工具内部并发由工具负责。
- sync 和 apply 支持停在 plan。保存已准备输入和计划，返回 0，不调用 OCR、不写本批正式语料、不编译图谱。人工显式恢复从未完成步骤继续。
- 每份差异清单与计划固定范围和输入版本，远端后续变化进入下一批。已有本地计划输入缺失或改变时要求重新生成；不能偷偷补入新内容冒充旧计划。
- 恢复只复用输入版本匹配且公开产物仍可用的明确成功结果。发现较新成功版本时拒绝旧计划回退；不自动重试已失败或结果不明的调用。
- apply 与图谱提交独立，图谱失败不回滚已成功更新的语料；manifest 只记录实际落盘结果，不提前宣称图谱成功。

### 起点、增量与产品策略

- 使用现有语料与图谱为起点，只登记新的程序状态，不重写既有正文或图谱、不运行历史提取、不导入旧 run 或状态格式。来源覆盖从工具公开产物取得，不能伪造当前远端版本等于本地旧正文版本。
- 来源身份为知识库与文档 ID。首次没有完整观察快照时，本地缺失 ID 使用本地语料最新日期作为新增选择截止；已有 ID 按各自精确版本判断，只有日期时同日也获取比较，避免遗漏同日更新。
- 后续以完整观察快照按 ID、版本、标题及路径差分，不改成 rolling 最近 N 天。首次已观察但有意过滤的历史缺失不反复当新增回填。
- 清单不完整则整批停止且不推进完整观察基线。完整清单中的缺席只记录移交，不自动删除语料或图谱贡献；改名、搬动和来源引用在同 ID 下正常维护。
- mdcompare 的公开报告决定正文复用、图片处理与元数据维护。明确复用则保留已有正文知识；新来源、正文变化、缺少旧输入或比较不确定时，当前完整输入有效就自动完整编译，不设人工审批或语义质量门槛。
- 正文复用不覆盖图片处理决策。图片变化或 OCR 补充影响编译输入时仍进入相应工具步骤；缺少当前完整输入时记录失败，不能用片段或旧内容冒充当前全文。
- OCR 尽力完成，单项失败和共享认证/额度错误由工具公开报告区分。有效历史结果与本次成功内容可用时继续，失败或未尝试项如实保留；不完整 OCR 不阻断正文编译。
- Graphify 按完整来源更新，成功来源继续发布，失败来源保留旧贡献和旧成功版本。公共存储或发布失败属于整批无法继续。

### 版本记录、恢复与失败交接

- 观察、下载、语料成功和图谱成功分别记录。只有实际成功才推进对应版本；比较复用确认、元数据维护和未完成工作不能混成一份虚假完成。
- 只保留精简的持久文档版本/步骤记录和每个 run 的计划、工具产物引用、执行结果。不另外建立阶段信封、异常四态处置、followup 和迁移标记平台。
- 工具启动前记录实际尝试的版本与步骤，结束后根据退出码和公开产物记录结果。中断且无可靠最终报告则标结果不明并移交；工具公开提交记录可以用来确认，不能通过重跑猜测。
- 同版本同一步骤失败或不明结果不参加日常自动尝试；新来源版本正常处理。从未启动的工作仍是未执行，能参加后续批次。OCR 失败不误阻断同版本正文编译等合法后续步骤。
- 中断批次不阻挡下一次 cron 创建新批次，人工仍可显式选择恢复旧 run。正常运行的同目标写进程互斥且不排队，只读监控不参与写锁；遗留记录不充当永久锁。
- 自身小型状态与结果原子替换，不建立新指纹机制、通用状态机或跨语料/图谱事务。工具内部提交与恢复依靠公开合同。
- 失败证据能定位 run、知识库与文档身份、版本、步骤、命令、退出码或原因、必要输入及工具报告。默认输出不包含认证值或文档正文。
- 过期 run 和失败证据由定时清理 agent 决定处理与删除。程序不扫描历史引用、搬迁或改写引用；run 清理不清除持久版本事实，不触发旧失败自动重试。

### 观察、输出与退出码

- status 支持按 run 查询、JSON 和前台 watch。默认查看正在运行或最近 run，无记录正常返回；结合实际进程与写锁识别遗留 running 为中断。
- 展示当前阶段、工具公开计数、耗时、最近进展和产物位置。没有公开细粒度进度时只展示运行与耗时，不从第三方日志推算百分比或业务成功。
- watch 只重复只读查询，不推进任务、不建后台服务；搭配 JSON 时逐行输出快照。
- stdout 输出命令结果，运行信息与第三方诊断实时进入 stderr 或必要日志，不能积存在内存等长调用结束。shell 保存普通日志，系统工具轮转。
- 0 表示完整完成、无工作或显式计划检查点；2 表示可用集合完成但存在部分失败；1 表示整批无法继续。参数错误为 64，SIGINT 为 130，SIGTERM 为 143。
- sync 聚合此前步骤失败，后续编译成功不能掩盖 OCR 等 partial。外部退出码按公开合同解释，不能机械透传；mdcompare 不确定报告经完整编译成功，并不自动构成整体 partial。

### 配置、规模与模块重切

- 编排器自行读取配置，承载知识库、路径、工具入口和编排策略；不使用 mdocr 的内部配置模型。工具缓存、模型、重试与资源处理参数仍由工具拥有，认证复用既有工具环境。
- 子进程使用 argv 列表，不拼 shell。不写死外部 Python 环境或私有模型，不建设任意参数透传或插件注册平台。
- 提取与图合并模块改为 Graphify 薄适配；OCR 运行时与自管缓存整体删除；比较输入构造和审批逻辑收敛为公开报告后的唯一产品策略。
- capture 保留选择、身份与观察，完整 listing/export 和表格内容渲染交 Skylark；工具缺口按前置任务解决。
- 多代执行器和兼容转发删除，状态、run、进度与结果模块合并职责；wash 清理与异常处置平台删除。CLI、doctor、只读监控、锁与时间处理只保留必要能力，doctor 不导入工具运行时。
- Web、生命周期及资源保留独立职责，必要时仅做配置解耦。工具可在各自源码补通用 CLI 能力，不要求拆仓库或重做发行体系，也不能把编排策略挪入工具伪装成瘦身。

### 工具合同前置任务与实施顺序

- mdcompare 已有 manifest 输入和 JSON 报告，需按公开报告和退出码映射集成；不能复用其 Python 类型、私有 parser 或算法。
- mdocr 的逐图选择、成功复用、失败/未尝试清单和结构化证据由其 CLI 提供，不能由编排器制造 prepared image 或 OCR block 的内部证明。
- Graphify 的整来源替换、部分失败保旧、逐来源成功报告、候选发布、来源清单与元数据维护能力，先核实公开合同，不足则补工具 CLI。现有命令名称不足以证明满足这些要求。
- Skylark 完整 listing/export 及表格导出需核实公开 MCP 能力，不足则上游补充。此前未访问远程网关，不把本机代码调查当线上能力证明。
- 先在工具侧确认并验证公共合同，再实现精简配置与版本记录、唯一命令调用链、监控和结果输出，同时移除旧执行器；最后完成合同验收、仓库必要门禁、隔离安装 smoke 和规模核对。不交付两套默认流水线并存的过渡成品。

## Testing Decisions

- **最高且主要的测试边界是可安装 dogpdkb CLI。** 该边界已随 Q1–Q14 和完整规格确认，无需再访谈或增加产品测试入口。测试通过真实本地 Markdown、临时语料/状态目录及外部 CLI/MCP 替身观察命令、产物、退出码和状态迁移。
- 不测试私有函数布局、比较内部得分、OCR block 格式、模型常量、JPEG 参数或图身份算法。工具自身 CLI 和算法回归留在工具侧；删除仅镜像被删除越界实现的测试。
- 先例沿用现有统一同步、capture 复用、计划、OCR、编译、状态/进度 CLI、真实 Markdown UAT 与安装 smoke 的验证方式，保留有效合同而非原测试内部布局。
- 核心静态边界守卫要求编排器对外部工具包零静态/动态导入，并拒绝自有脚本绕回内部实现；这是职责守卫，不建设通用审查框架。
按以下 12 组外部可观察场景验证，不新增仅为测试服务的产品接口：

1. 安装后的分步命令与 sync 行为一致；全批下载、比较、计划、OCR、编译严格有序；计划检查点不调用后续工具、不写正式语料，显式恢复只推进未完成工作。
2. discover 不下载正文；首次截止、已有来源同日比较、后续完整快照差分和历史缺失不回填均有真实文件覆盖。
3. 完整清单失败不推进基线；缺席不删除；改名和搬动保持身份并维护元数据。
4. 明确复用、新增、比较不确定、缺少旧输入和正文相同但图片变化走正确产品动作，不断言比较算法内部语义。
5. OCR 成功、partial、共享错误、未尝试和不明结果按公开报告形成可用输入与交接，不复刻 OCR 运行时。
6. apply 实际更新语料；单来源编译失败保留旧贡献，成功来源发布；语料成功不能推进失败图谱版本。
7. 0/2/1、参数错误和中断码符合合同；sync 聚合失败；mdcompare 不确定报告不机械等同整体 partial。
8. 同版本同一步骤失败不自动重试，新版本仍参与；agent 清除 run 后仍成立；OCR 失败不阻断正文编译。
9. 中断或不明结果可见且不挡新 cron；从未执行项仍可处理；恢复复用成功结果并拒绝版本回退。
10. 旧计划输入改变或缺失时明确拒绝，不偷偷下载新版本继续旧计划，旧 manifest 不覆盖更晚结果。
11. 同目标写互斥；status 的 run、JSON、watch 只读且可停止观察；遗留 running 可识别，输出实时可重定向且无凭证。
12. 不存在旧执行器、工具内部调用、自动 wash 清理或 sync 隐式 Web 发布；统计实际编排器行数。
- CLI 替身合同测试、离线 mdcompare 实跑、独立工具测试、仓库门禁、隔离安装 smoke、付费真实 OCR/Graphify 与生产验收分别报告，不能互相冒充。普通规格发布不执行付费或生产任务。

## Out of Scope

- 旧入口参数、旧 run、checkpoint、状态格式与历史下载记录迁移；保留有用命令不等于保留旧执行器。
- 历史缺失回填、全量重新提取或随意重建现有图谱。
- 编排器内部的 OCR 运行时、比较器、缓存算法、图合并器、外部工具包导入或私有 API 适配。
- 人工审批流程、业务语义质量门槛、异常四态处置平台、followup 平台、历史引用扫描搬迁和自动 wash 清理。
- 自动跨批重试失败版本、自动恢复旧 run、通过重跑确认不明提交结果。
- 常驻调度器、消息队列、工作流引擎、编排器并发工作池、监控后台服务、新监控前端、内置日志轮转。
- 自动远端缺席删除、旧计划覆盖较新成功版本。
- 将 Web 发布加入 sync，改造 Web 产品行为，拆分工具仓库或重做发行体系。
- 定时清理 agent 的调度、模型与自主处置实现，自动安装 cron 或 logrotate。
- 本次规格发布时修改实现、启动实际同步/OCR/提取、操作生产数据、部署或发布软件版本；这些不由规格定稿授权。
