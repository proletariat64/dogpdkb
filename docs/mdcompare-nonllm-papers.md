# Markdown 知识库更新去重：非大模型论文与方案

## 结论与边界

建议先做**离线、无模型、保守判定**：Markdown 结构解析 → 文档候选检索 → 块/句对齐与移动识别 → 表格结构比较 → 事实敏感字段变更提示 → 人工复核。相似不等于重复，更不等于事实不变；默认不自动删改原文或合并知识。792 篇是已冻结的 v3 候选集，已知其中 770 篇有配对旧文、22 篇没有；字符分布见 [v3 字符统计](mdcompare-v3-character-stats.md)。以下两两规模仅作上界估算，不是建议执行的检索范围。独立两两比较是 792×791/2＝313,236 对；若是 792 篇新文对 792 篇旧文则是 627,264 对，已有稳定文档 ID 时先按 ID 配对。句子级全量交叉比较可能远大于文档对数，应先筛候选。

研究只访问公开论文信息，未下载模型、未发送或引用私有正文，也未测试 792 篇数据。Kimi datasource/arXiv 尝试返回缺少 Kimi Code OAuth，故使用公开 web 搜索与原论文页面；不需要登录或补充凭据。下文区分论文原结论与为本任务提出的设计，性能均未经本语料验证。

## 无模型方案

### 1. 候选与近重复：shingles / 集合相似与包含

**原论文：** Broder, *On the Resemblance and Containment of Documents* (1997)，[论文 PDF](https://www.cs.princeton.edu/courses/archive/spr05/cos598E/bib/broder97resemblance.pdf)。论文以 shingles 研究 resemblance 和有方向的 containment，并介绍采样估计；不保证业务事实等价。

**适配与可实现性：可实现。** 按 Markdown AST 提取正文与表格，保留章节及来源；中文可用字符 n-gram，不依赖分词模型。计算精确 shingle 集合 Jaccard，并双向计算包含率，召回全文近似和短文包含于长文的候选。792 篇先试直接集合比较与倒排索引；只有实测不足时再考虑论文中的抽样/MinHash 索引，不为规模预先引入复杂指纹。确切重复须在受控规范化后直接比较完整内容，并保留原始字节和来源，规范化策略须明确。

**风险：** 模板、目录和共同免责声明造成高分；短文、数字/否定变化和跨语言改写可误判。shingle 长度、候选 top-k 和阈值需标注集调优。候选截断会造成漏召回，不用相似度直接删除。

### 2. 块与句子的对齐和移动

**原论文：** Myers, *An O(ND) Difference Algorithm and Its Variations* (1986)，[作者所在机构论文页](https://www.janelia.org/publication/ond-difference-algorithm-and-its-variations)，[论文 PDF](https://par.cse.nsysu.edu.tw/resource/lab_relative/Myer86.pdf)。Jiang 等，*arXivEdits: Understanding the Human Revision Process in Scientific Writing* (2022)，[arXiv:2210.15067](https://arxiv.org/abs/2210.15067)。后者提供论文修订句对齐语料，报告的神经 CRF 句对齐结果属于论文实验，**不是无模型方法，也不能转移为中文业务指标**。

**适配与可实现性：可实现。** 使用标题层级、段落/列表/代码块构成层次；同章节先对完整相同块直接匹配，余下用字符 n-gram 相似度加动态规划对齐，支持 1:1、1:多、多:1 和空匹配；再对齐局部运行 Myers 字符或 token diff。对未配对的删除块与新增块全局做精确匹配，标记移动候选；再以相似度和上下文章节生成“移动并修改”候选。重复句需一对一分配、保留并列候选与置信度，不得把单调 diff 自身视作移动识别。

**风险：** 中文句界、缩写、列表、代码与跨章节重排会破坏对齐；大规模重组和拆句/合句存在歧义。精确重复文字在不同语境可能是复制而非移动；必须展示原/新位置及前后片段供复核。

### 3. 事实敏感改动提示：字段规则，不宣称事实验证

**原论文：** Schuster 等，*Get Your Vitamin C! Robust Fact Verification with Contrastive Evidence* (2021)，[arXiv:2103.08541](https://arxiv.org/abs/2103.08541)。该研究使用对比证据探究事实核验；不是本文规则式方案的性能证明。

**适配与可实现性：可实现规则基线；无法完整判断事实。** 对已对齐文本比较数字、币种、百分比、日期、上下界、否定词、条件词、实体字面值和 URL；与原文及偏移一起输出变更提示，不抹去单位或否定。定义严格可追溯的数值/单位规范化；不确定时保留原值。例子用合成测试数据，不外发真实文本。

**风险：** “未变化”只意味着指定规则没命中，不是事实等价；同义改写、隐含条件、指代、范围作用域、版本生效时间、上下文和计算关系均可能漏检，数字变化亦可能无业务影响。缺少外部可信证据时不能判断哪版为真。

### 4. 表格、行列与单元格对齐

**原论文：** Bleifuß 等，*Table and Cell Matching Across Web Page Revisions* (CIKM 2020)，[作者机构论文 PDF](https://hpi.de/fileadmin/user_upload/fachgebiete/naumann/projekte/ChangeExploration/WikipediaDataEvolution/Table_and_Cell_Matching_Across_Web_Page_Revisions_latest.pdf)。论文研究网页版本中的表和单元格匹配；迁移至 Markdown 需独立验证。本次作者机构 PDF 直取时 DNS 失败，标题和研究方向由公开搜索摘要核对，尚未核对算法细节，勿当作复现说明。

**适配与可实现性：可实现基线。** 用解析器识别 Markdown 表格（含转义竖线），按标题/相邻章节/表头/内容生成表级候选；优先用可证明唯一且稳定的业务键匹配行列，无键时用相似度构造候选并匹配，逐单元格比较值；单独标出行列移动、增删与改值。HTML 表、合并单元格与嵌套结构应单独解析或标记不支持，不静默忽略。

**风险：** 键重复或发生重命名、转置、合并/拆分与多个相似表造成错误对齐；格式不规范或图片表格无法由文本解析复原。数值单位、空值和列语义变化须人工复核。

## 需训练或下载模型的可选方案（本次均未执行）

### 5. 句向量候选召回

**原论文：** Reimers 和 Gurevych, *Sentence-BERT* (2019)，[arXiv:1908.10084](https://arxiv.org/abs/1908.10084)；Feng 等，*Language-agnostic BERT Sentence Embedding* (2020/2022)，[arXiv:2007.01852](https://arxiv.org/abs/2007.01852)。前者提出句向量余弦比较；后者报告多语言检索。LaBSE 并非轻量模型的保证，具体大小和部署资源取决于权重。

**适配与可实现性：条件可实现。** 若本地批准并提供合规中文/多语言编码器权重，可对候选段落或句子离线编码、召回改写/跨语言候选；只送候选给后续结构对齐和规则检查。也可选择更小的编码器，但须单独核查许可证、权重体积、中文领域效果与安全要求，不假定 SBERT 所有变体都小或支持中文。

**风险：** 模型训练与加载需要权重、算力和供应链审查；余弦近可能包含相反结论，不能据此判同义或自动去重。私有向量和缓存仍是敏感数据；需本地访问控制、生命周期管理。跨域、短句、截断和阈值均需测试。

### 6. 文本蕴含 / 矛盾分类

**原论文：** Conneau 等，*XNLI: Evaluating Cross-lingual Sentence Representations* (2018)，[arXiv:1809.05053](https://arxiv.org/abs/1809.05053)；以及上述 [VitaminC](https://arxiv.org/abs/2103.08541)。XNLI 是多语言评测集，不是可直接部署的现成小模型；VitaminC 是对比证据事实核验研究，不证明金融中文表现。

**适配与可实现性：条件可实现。** 在授权获得或训练支持中文的本地 NLI 分类器后，对少量已对齐高风险候选进行旧→新、新→旧双向推断；双向蕴含可作为等价的弱证据，单向蕴含、矛盾、未知则进入复核。分数需校准与拒判机制；以规则字段差异和原文证据覆盖模型输出。

**风险：** 即使双向蕴含也可能错判数字、日期、否定、长上下文和业务术语；矛盾不等于哪一版正确。模型可能较大，压缩或蒸馏需要额外训练和评估；不能把小模型与无模型混为一谈，也不能用大型生成模型冒充该方案。

## 建议落地与验收

1. 保留源文件及版本，建立稳定来源映射；正文读取/解析失败和不支持的正文表格须显式保留待判。图片及 OCR 完全不参与比较、不产生待办，也不阻塞正文判断。
2. 先按 ID 对齐版本；无 ID 时候选召回，再做块/句、移动、表格与高风险字段比较。结果类型至少包括完全一致、候选近似、增删、移动、修改、冲突/疑似事实变更和未知；每项记录双向来源、位置、规则及复核状态。
3. 分层抽样构建本地人工金标：独立文档、不同版本、模板、中文改写、否定/数字/日期、移动、拆合句、重复行列、图片/解析失败。数据集按文档或版本族隔离，防泄漏；同时采样未召回对以估计候选召回率。
4. 分别报告候选召回率、重复判断精确率、句对齐与移动的精确率/召回率、事实敏感变更召回率及误报、表格单元格对齐质量、人工工作量、耗时和内存；按文档类型分层并报告样本量与置信区间。阈值和发布门槛由业务风险与标注结果确定，不预设论文数值适用。
5. 初期只生成可审计报告，不自动删除、覆盖或合并；对高风险项、低置信与未支持内容保留人工决策。
