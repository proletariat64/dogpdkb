# v3 候选正文 diff：排除明确富化区块后重算

本结果取代 `mdcompare-v3-diff-stats.md` 中受污染的历史统计。冻结主批次 792 篇候选：770 篇有同 ID 旧版，其中 654 篇有 `updated` 标签；另 22 篇为新文档，无成对 diff。

## 口径与限制

- **仅统计**：明确 `mdocr:ocr-begin` 到 `mdocr:ocr-end` 的生成区块，即使在围栏内也先排除；图片及已识别的明确旧生成注释不参与。未知来源的未标记正文不猜测、不删除。
- 将围栏标记、反引号、行首空白视为本统计的展示差异，并用 `_prose_key` 归一化白名单 HTML 展示标签和明确数量单位；未知 HTML、正文链接与非空内容保留。这是特定**统计视图**，不是产品的代码/表格语义比较；可能忽略有意义的代码差异，也可能保留其他格式噪声。
- 1 篇旧文的历史生成注释未闭合，无法可靠确定结束边界；该篇只标为无法统计，不猜测、不纳入分布。故 770 篇中有 769 篇可统计；654 篇 updated 中有 653 篇可统计。
- 每篇 diff 为新增 + 删除字符。先对行用 SequenceMatcher 对齐，再对较短替换区做字符级启发式比较；替换区超过 20,000 字符时计整块，13 篇涉及该近似。结果不是最短编辑距离或业务知识增量。
